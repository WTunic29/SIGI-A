# JavaScript del frontend

- `config.js`: URL base del backend.
- `main.js`: navegación principal, login, registro, roles, tienda, citas y dashboards.
- `mfa.js`: configuración inicial del MFA con QR.

Nota: `main.js` se conserva completo para reducir riesgo de romper funcionalidades existentes. Ya queda preparado con ruteo por páginas HTML (`login.html`, `usuario.html`, `negocio.html`, etc.).
